## Overview

**KRONA** is a concept agency site designed to experiment with high-end frontend design, smooth motion, and clean dark-mode aesthetics.

- **Clean Dark Theme:** Built on a `#09090b` palette with Geist typography.
- **Interactive Case Studies:** Modal breakdowns covering challenges, tech stacks, and results.
- **Interactive Tools:** Includes a client logo marquee, an interactive scope/pricing calculator, and a multi-step inquiry form.
- **Responsive & Accessible:** Mobile-first layout with keyboard shortcuts (like `ESC` to close modals).
